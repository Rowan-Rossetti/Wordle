Comment jouer

100 fonctionnalités et règles actives, regroupées par catégorie.

Règles de base

  1. Trouvez le mot avant la fin des essais.
  2. Le mot doit avoir la longueur demandée.
  3. Le mot doit appartenir au dictionnaire français.
  4. Les accents et la casse sont normalisés.
  5. Un même mot ne peut pas être proposé deux fois.
  6. Les doublons sont évalués précisément.
  7. Une case verte indique une position exacte.
  8. Une case orange indique une autre position.
  9. Une case grise indique une lettre absente.
  10. Une partie terminée ne peut plus être modifiée.

Mode strict

  1. Les lettres vertes restent obligatoirement en place.
  2. Les lettres orange doivent être réutilisées.
  3. Une lettre orange ne peut revenir à sa mauvaise position.
  4. Les lettres exclues sont interdites.
  5. Le nombre minimal de doublons révélés doit être conservé.
  6. Les contraintes se cumulent à chaque essai.
  7. Le mode difficile impose le strict.
  8. Le mode expert impose le strict.
  9. En expert, le premier mot doit avoir 4 lettres différentes.
  10. Le mode expert limite la partie à 5 essais.

Modes de jeu

  1. Le mode aléatoire choisit un mot inédit.
  2. Le défi quotidien est identique toute la journée.
  3. Le mode chrono impose une limite de temps.
  4. Le mode zen retire la pression du chronomètre.
  5. La difficulté détente offre 8 essais.
  6. La difficulté normale offre 6 essais.
  7. Les longueurs vont de 4 à 8 lettres.
  8. Le choix Surprise varie la longueur.
  9. Quitter le site crée un nouveau mot au retour.
  10. Changer de page conserve la partie dans la session.

Aides et progression

  1. Trois indices maximum par partie.
  2. L’indice Lettre révèle une lettre présente.
  3. L’indice Voyelle révèle une voyelle disponible.
  4. L’indice Position révèle une position exacte.
  5. Les indices sont désactivés en expert.
  6. Chaque victoire rapporte de l’XP.
  7. Les performances rapides donnent plus d’XP.
  8. Les indices réduisent la récompense.
  9. Les niveaux progressent tous les 500 XP.
  10. Douze succès peuvent être débloqués.
  11. Les statistiques sont enregistrées localement.
  12. L’historique conserve 100 parties.
  13. Les mots tirés ne se répètent pas.
  14. Le résultat peut être partagé sans révéler le mot.
  15. Les données peuvent être exportées en JSON.
  16. Le thème clair et sombre est mémorisé.
  17. Un mode daltonien est disponible.
  18. Le contraste renforcé est disponible.
  19. La taille du texte peut être augmentée.
  20. Les animations peuvent être réduites.
  21. Le clavier AZERTY ou QWERTY est sélectionnable.
  22. Le son et les vibrations sont facultatifs.
