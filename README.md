# Motus Angular

Jeu de mots entièrement reconstruit avec Angular 20.

## Fonctionnalités

- Mots français de 4 à 8 lettres
- Longueur aléatoire ou sélection manuelle
- Six essais par manche
- Clavier AZERTY tactile et clavier physique
- Couleurs synchronisées entre la grille et le clavier
- Gestion correcte des lettres présentes plusieurs fois
- Validation des propositions avec le Wiktionnaire
- Passage automatique au mot suivant après cinq secondes
- Bouton permettant de passer immédiatement au mot suivant
- Statistiques et préférences enregistrées localement
- Thèmes sombre et clair
- Interface adaptée aux ordinateurs et téléphones

## Lancement

```bash
npm install
npm start
```

## Compilation

```bash
npm run build
```
